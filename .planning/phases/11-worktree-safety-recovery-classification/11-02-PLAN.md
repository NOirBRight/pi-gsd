## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Orchestration Unit → filesystem/Git root | A source-writing Unit crosses from runtime control flow into a working tree that can modify source files. |
| Lease record → dispatch permission | Disk lease evidence controls whether a Unit may write in a root. |
| Environment/CWD → expected project root | Process cwd/env can point at the wrong repository or branch. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-04 | Tampering | `prepareUnitRoot` | mitigate | Resolve and compare project/unit roots, require `.git`, branch, and GSD_PROJECT_ROOT checks, and return typed worktree-invalid on mismatch. |
| T-11-05 | Elevation of Privilege | `lease.ts` | mitigate | Bind lease to unitId/session/phase/branch/process/host evidence and reject wrong-owner or contradictory stale leases. |
| T-11-06 | Tampering | branch validation | mitigate | Never call checkout/switch; branch mismatch returns typed stop decision with remediation. |
| T-11-07 | Information Disclosure | worktree/lease evidence | mitigate | Evidence uses bounded D-18 fields only and avoids raw env/user text/secrets. |
| T-11-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan; if executor adds one, stop and require package legitimacy review. |
</threat_model>
