## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Worktree safety decision → orchestrator gate | Validation failure controls whether dispatch continues, pauses, retries, or stops. |
| Lease event → orchestrator journal | Lease evidence crosses from runtime memory into durable `.planning` state. |
| Recovery decision → journal/status persistence | Bounded telemetry crosses from runtime memory to disk under `.planning/`. |
