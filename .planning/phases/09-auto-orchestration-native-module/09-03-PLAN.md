## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args → dispatch adapter | User-controlled command args choose mode, phase, cwd, resume/status/stop behavior. |
| Dispatch adapter → child/Pi runtime | Native code launches or delegates workflow-step Units. |
| Prompt transform → generated/runtime prompts | Removing checklist must not break syntax transforms or add behavioral prompt content elsewhere. |
| E2E fixture → filesystem gates | Fake Unit dispatch writes artifacts consumed by gates. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-09 | Tampering | CLI `--cwd` and `--phase` | mitigate | Resolve cwd, validate phase string against safe phase-id pattern, and constrain journal/artifact writes under fixture/project `.planning/`. |
| T-09-10 | Command Injection | `src/orchestrator/dispatch.ts` | mitigate | Dispatch runner receives argv arrays and typed Unit payloads; do not concatenate shell command strings from Unit IDs or user args. |

| T-09-13 | Elevation of Privilege | unsafe resume/stop CLI | mitigate | `--resume` reads validated journal snapshot; `--stop` requires explicit reason and writes stopped status rather than dispatching. |
