## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Orchestrator → `.planning/orchestration-state.json` | Runtime writes machine-readable lifecycle state to disk. |
| Journal → resume() | Persisted state controls which Unit runs next after session boundary. |
| Orchestrator → `STATE.md` handler | Digest pointer update crosses into upstream-managed project memory. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-05 | Tampering | lifecycle journal | mitigate | Resolve journal under `.planning/`, validate schema on read, and reject outside paths before writes. |
| T-09-06 | Information Disclosure | journal events and status | mitigate | `redactJournalEvent` omits raw prompts, user text, env, tokens, secrets, and unbounded args per D-17. |
| T-09-07 | Elevation of Privilege | unsafe resume behavior | mitigate | `resume()` only resumes a known unfinished Unit from a validated closed Unit union and refuses `completed`/`stopped` snapshots. |
| T-09-08 | Repudiation | STATE digest pointer | mitigate | Detailed replayable event history stays in journal; STATE digest handler writes only current pointer/status through `gsd-tools` seam. |
| T-09-SC | Tampering | npm installs | accept | Phase 9 Plan 02 adds no package-manager install tasks; Package Legitimacy Audit states no new packages. |
</threat_model>
