<objective>
Add an interim best-effort guard to pi-gsd-redux that pre-cleans pi-subagents temp directories before the subagent extension loads, and an ACL corruption diagnostic to the doctor command. Per D-03, monkey-patch is viable as interim measure but fragile — this guard is a safety net while the upstream PR (Plan 01) is pending.

The interim guard reduces the crash surface by attempting to clean corrupted directories before pi-subagents loads. The doctor check helps users diagnose ACL corruption and tells them exactly what repair script to run.

Output: guardPiSubagentsTempDirs() in extension.ts, ACL check in doctor.ts, tests for both.
